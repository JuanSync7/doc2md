# Agent rules — `docs/reference/`

Inherits from the root, `CONVENTIONS.md` and `docs/CLAUDE.md`; the more specific
(this) file wins. `docs/CLAUDE.md` allows `reference/` to thinly mirror the code —
that permission is what this directory exists under.

## Rules

- **Never hand-edit `vocabulary.md`.** It is generated by
  `scripts/render_vocab_doc.py` from `config/vocab.yaml`. Change the data and
  regenerate; a hand edit is reverted by the next run and fails `--check`.
- **A reference entry is not done until its parity test passes.** Adding a switch,
  an env var or an artifact key means updating the matching table here in the
  *same* change — `tests/integration/test_docs_parity.py` enforces it.
- **Document the effect, not the flag.** "`--force`: rebuild even when a bundle
  exists" is a restatement of the help string and worth nothing. Say what appears
  in the output that would not otherwise, and what is destroyed or preserved.
- **Record the traps.** A flag that is silently ignored, a value that reverts to a
  default when malformed, two flags that share a name and differ in behaviour —
  those are the entries a reader actually needs. Do not tidy them away.
- Look-up voice: tables over prose, no tutorial narrative. Narrative belongs in
  [`../guide.md`](../guide.md).
